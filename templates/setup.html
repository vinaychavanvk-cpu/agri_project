How to connect on Vercel:

  1. Create a free cloud PostgreSQL database on Neon.tech or Supabase.com.
  2. Copy your connection string (URL) which looks like:
    postgresql://user:password@host/dbname?sslmode=require
  3. In your Vercel Dashboard, go to: Project → Settings → Environment Variables.
  4. Add a new variable named DATABASE_URL and paste your connection string.
  5. Redeploy or reload this page. The system will automatically create the tables and seed initial data!
